# Static SM01 Comparison - 2026-08-27

## Scope

This report closes Phase 2E.4 for the frozen `SM01_preference_adoption`
path. It compares three method variants over three independent, unseeded
replicates:

- `no-persistence`: native+ledger observation, persistence disabled.
- `native-hermes`: native+ledger observation, Hermes native memory writes.
- `static-rsimem`: native+ledger observation, Hermes native memory writes
  disabled, deterministic lifecycle boundary plus Mem0-flat semantic writeback.

The model was `gpt-5.6-luna` at temperature 0.0. The judge was disabled;
task scores came from the benchmark grader after execution and were never
available to the online policy. Model, task order, task budgets, sandbox,
failure policy, and per-attempt persistence isolation were fixed. The provider
does not expose a controllable seed, so these are rotated independent
replicates rather than seeded repeats.

Accepted batch:

- Batch: `outputs/static_sm01/hermes_luna/static_sm01_20260827_v3`
- RSIMem commit: `f62285ae0793624a2f40ba55845dbcaa37be7697`
- PAST-Bench tree: `145326fa9cec3c5c8fa54dc285f016edeaf59726`
- Attempts: 9 completed, 0 failed; 81 unique traces.
- Audit: all 9 reports have `ok=true`; zero credential-pattern hits, memory
  text leaks, unresolved injections, adapter bypasses, or projection mismatches.

The earlier `v1` and `v2` batches are excluded. They are retained as
infrastructure-failure evidence for, respectively, single-variant audit
normalization and static runtime attribute joins.

superiority claim.

## Lifecycle Outcome

Replicates 2 and 3 committed the semantic `ADD` during learn A. The memory was
then present in the `sm01_post_learn` history anchor and injected in learn B,
eval-near, and eval-far. Replicate 1 committed its only `ADD` during reflection,
after the post-learn anchor had been frozen, so its evaluation episodes had no
memory injection. This is policy timing variance, not a storage or restart
failure.

The first live semantic lifecycle is therefore reproducible and auditable at
the contract level, while admission timing remains a measured method weakness.
The result establishes a static baseline only. It does not demonstrate adaptive
policy updates, delayed utility learning, or recursive self-improvement.
